# CreatorHub Website

A responsive, single-page creator application website built with HTML, CSS, and JavaScript.

## Features
- Applicants must be 13 or older
- Applicants need at least 10 followers
- Multi-step application form
- Content category selection
- Privacy and community safety acknowledgements
- Application review and demo confirmation
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new repository, for example `creatorhub`.
3. Upload `index.html` (and this README) to the repository's root.
4. Open the repository's **Settings**.
5. Choose **Pages** in the sidebar.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and `/(root)` folder, then click **Save**.
8. Wait for GitHub Pages to publish the site. The Pages section will show the public URL.

## Important demo limitations
This is a front-end prototype. Applications are not sent to a server, accounts are not created, and form data is not saved online. The age check is a basic date-of-birth check, not secure age verification. Do not collect real users' personal information with this demo. Before launching a real service, add a secure backend, access controls, appropriate privacy disclosures, age-appropriate safeguards, and a process for handling and deleting application data.
