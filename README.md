# CreatorHub email application form

This version uses one page: there are no numbered steps and no Continue button. Applicants must enter their email address.

## Deploy
1. Extract this ZIP.
2. Upload `index.html` to the **root** of your GitHub repository.
3. In GitHub **Settings → Pages**, choose **GitHub Actions** as the deployment source.
4. Wait for the Pages workflow to finish and open the repository's Pages URL.

## Email forwarding
Applications are configured to forward to `daviolvcass@gmail.com` through FormSubmit. The first test submission may require confirming the recipient through an email sent by FormSubmit. Test it before sharing the website. This is a third-party service and email delivery depends on it; this static page does not store applications in a database.

Never ask applicants to submit passwords, verification codes, home addresses, or sensitive documents.
